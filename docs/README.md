# Documentación del Motor DPM

Documentos funcionales y técnicos del motor (diseño de la solución, guía práctica, manuales).

`cambios_pendientes_de_documentar.md` recoge los cambios hechos en el código, las tablas
y la parametría que todavía no están en los documentos. Cuando un cambio pase a la
documentación, se quita de esa lista.
