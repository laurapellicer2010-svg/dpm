# Motor DPM

Notebooks, SQL y parametría del Motor DPM (reporting regulatorio en Microsoft Fabric).

| Carpeta | Contenido |
|---|---|
| `notebooks/` | Notebooks de Fabric (`.ipynb`) |
| `sql/` | Scripts SQL de despliegue y de mantenimiento, y consultas del día a día (`Motor_DPM_Consultas_dia_a_dia_notebook.sql` para Spark SQL en notebook, `Motor_DPM_Consultas_dia_a_dia_TSQL.sql` para el SQL analytics endpoint) |
| `parametrization/` | Excels de parametrización por framework |

La versión que se ejecuta es la de Fabric; este repositorio guarda el historial de los cambios.
